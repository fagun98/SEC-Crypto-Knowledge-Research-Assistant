Pipeline flow:

1. Fetch pages (SEC/CFTC/OCC/FDIC/Fed/state) on a schedule.

2. Normalize text (strip nav, remove boilerplate, keep headings).

3. Chunk by section/heading/paragraph (don’t classify the whole page).

4. Keyword gate: score chunks; pass only chunks that hit custody keywords (plus keep a tiny random sample for QA).

5. LLM classify + tag only the passed chunks:
    - relevant? (yes/no)
    - entity types (BD/RIA/bank/trust/custodian)
    - topics (segregation/key mgmt/qualified custodian/etc.)
    - severity (critical/high/medium) + confidence + 1-line reason

6.Store
    - Raw doc → cheap storage (for audit + reprocessing)
    - Relevant chunks → your searchable KB + embeddings
    - Reject log → chunk hash + decision + reason (no need to embed)

7. Build tables/views
    - tracker table (date, source, type, status, tags, summary pointer)
    - weekly digest generator uses “new relevant chunks this week”
